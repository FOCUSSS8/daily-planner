# 每日计划 · Daily Planner

一个**本地优先**的每日计划工具：把一天分成上午、下午、晚上三个时段，各定一个重点；用分组待办清单记录要做的事；晚上用三个问题做一次简短复盘。

数据保存在你自己的电脑上，零成本、零账号、无第三方依赖。手机连同一个 WiFi 时，可以通过局域网访问同一份数据。

## 功能

- **三时段重点**：上午 / 下午 / 晚上各一个最想推进的目标
- **分组待办**：学习 / 工作 / 健康 / 其他，支持回车添加、圆圈勾选、双击改文字、删除
- **晚间复盘**：完成了哪些重点？哪段时间浪费了？明天最想改善什么？
- **自动保存**：输入即保存，无需点保存按钮
- **日期切换与历史**：可回看过去每天的重点、完成率和复盘状态，支持按月浏览
- **导出 / 导入**：一键把全部数据导出为 JSON 备份，换电脑时导入还原
- **手机访问**：手机连同一 WiFi 即可打开同一份数据

## 快速开始

需要 [Node.js](https://nodejs.org) 20 或更高版本（无第三方依赖，无需 `npm install`）。

```bash
node server.js
```

然后打开 <http://127.0.0.1:3210>。

Windows 上也可以直接双击 `start.bat`。

## 手机访问

1. 手机连接和电脑**同一个 WiFi**
2. 启动服务后，终端会打印一行形如 `http://192.168.x.x:3210` 的地址
3. 在手机浏览器打开该地址

首次启动时如果 Windows 防火墙弹窗，请勾选「专用网络」并允许访问，否则手机连不上。

## 桌面应用窗口（可选，Windows）

仓库里的 `launch.vbs` 会先确认后台服务在运行，然后用 Edge 的应用模式打开界面（没有地址栏和标签页，像一个独立软件）。

用法：给它创建一个快捷方式放在桌面或任务栏，双击即可。关闭这个应用窗口约一分钟后，后台服务会自动退出；页面底部的「退出」按钮可以立即停止服务。

## 数据

- 数据文件默认位于 `data/planner-data.json`
- 该目录已被 `.gitignore` 排除，你的计划内容不会被提交
- 建议定期用页面底部的「导出备份」保存一份 JSON

## 项目结构

```
server.js          零依赖 HTTP 服务：静态文件 + JSON API
store.js           数据读写层（原子写入，损坏保护）
public/
  index.html       页面结构
  styles.css       界面样式
  app.js           前端逻辑：自动保存、日期与历史、备份
test/              node:test 测试（数据层 + API）
start.bat          Windows 启动脚本
launch.vbs         Windows 桌面启动器
```

## 开发

```bash
npm test        # 运行全部测试
npm start       # 等价于 node server.js
```

## 环境变量

| 变量 | 默认值 | 说明 |
| --- | --- | --- |
| `PORT` | `3210` | 监听端口 |
| `DATA_FILE` | `data/planner-data.json` | 数据文件路径 |
| `OWNER_GRACE_MS` | `60000` | 主人窗口关闭后，服务自动退出的等待时间 |

## 技术说明

后端只使用 Node.js 内置模块，数据以单个 JSON 文件持久化（先写临时文件再重命名，避免写坏）。前端是原生 HTML/CSS/JavaScript，没有构建步骤。
